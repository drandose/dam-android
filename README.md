# Prácticas de Android (2º DAM)

Están hechas en Java con Android Studio y con API 26 como versión mínima. Cada carpeta es un proyecto de Android Studio independiente.

| 03 | PracticaTextView2 | 16/10/2026 | EditText y TextView (saludo con nombre y apellido) |
| 04 | PracticaButtonTextViewYText | 16/10/2026 | Calculadora con if y switch |
| 05 | PracticaCheckbox | 19/10/2026 | CheckBox y Switch |
| 06 | PracticaRadioButton | 22/10/2026 | RadioButton y RadioGroup (calculadora) |
| 07 | PracticaSpinner | 23/10/2026 | Spinner con ArrayAdapter (calculadora) |
| 08 | PracticaSwitch | 23/10/2026 | Switch |
| 09 | PracticaDados | 27/10/2026 | ImageButton e ImageView (dados) |
| 10 | SelectorVisual | 06/11/2026 | Spinner con imágenes (BaseAdapter) |
| 11 | TresEnRaya | 10/11/2026 | TableLayout (tres en raya) |
| 12 | NavegacionActivity | 13/11/2026 | Intent (cambio de Activity al pulsar una imagen) |
